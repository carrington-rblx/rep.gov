# Representative Winters - Official Portal

**Domain:** www.winters.representative.rogov  
**Repository:** carrington-rblx/rep.gov

A full production-ready Next.js 14+ (App Router) constituent services portal for U.S. Representative Winters.

## Stack
- Next.js 14+ App Router + TypeScript (strict)
- Tailwind CSS with exact design tokens from the John Curtis reference
- Lucide React icons
- React-Simple-Maps + D3-Geo for interactive district map
- Octokit for admin GitHub auto-sync pipeline

## Design System
- Primary Navy: `#002B49`
- Dark Navy Cards: `#001F3F`
- Accent Gradient: `linear-gradient(135deg, #E28743 0%, #EAB308 100%)`
- Fonts: Montserrat (sans) + Playfair Display (serif)

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Key Routes
- `/` — Homepage (Hero + Latest News + Services + Offices)
- `/find-your-representative` — Interactive district map
- `/about/voting-record` — Searchable voting record
- `/your-priorities` — Constituent priority form
- `/admin` — Staff CMS (protected)
